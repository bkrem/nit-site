Nit

Review GitHub pull requests on your phone, using your own AI.

Nit is a native iOS app for the review you would otherwise put off until you are back at a laptop. Open a PR, read a diff that is readable on a phone, select a few lines and ask your own model about them, then comment, set a verdict, and merge.

Nit has no backend. Your phone talks straight to GitHub and to whichever AI provider you configure. There is no account to create and no analytics.
